Flood Alert and Community Reporting System
Project overview
This repository contains the logical design for a proposed system to collect and organize flood-related reports from residents and community coordinators in Freetown, Sierra Leone.
Contents:
. Assignment report
. Coloured flowchart
. Pseudocode
. Algorithm design
Scope
This is a logical design for a programming logic assignment, not a live flood-warning application. The sample alert rules are illustrative and are not official flood-safety criteria.
